# Suanpan · 算盘课

A 9-rod Chinese abacus (上二下五) to learn the 52 addition / subtraction rhymes: 10 lessons × 8 problems, random practice,
free play. v0.1.1 two-stage input (profile D17 >= 2°): tap a rod deck (eye + pinch or controller ray + trigger); the
upper deck flips the five, the lower deck opens a 0–4 "how many at the bar" key row in front of it; the beads slide as a group;
the board is judged by its value only whenever the beads settle. PICO OS 6, Kotlin, PICO Spatial SDK 6.1.9 (BOM),
package `io.embodit.suanpan`, v0.1.2. Built by the spatial-app-factory build station (kj-home-pc, 2026-11-11).

Design package (binding): `../spatial-app-factory/apps/suanpan-abacus/design-package.json` (states S00–S16, interactions
T1–T16, content.lessons, whyTemplates). Engine reference: `../spatial-app-factory/apps/suanpan-abacus/koujue_reference.py`.
Skeleton from Cloud Air (volume + Planar control window); board input from the factory template `taste/templates/board-input`.


Rules kept here: ECS for every per-frame motion (never Compose); resources created off the main thread, 63 beads in three
frames; a slide's result is in the state before it plays; the judge runs on each rod's settle timer (slide + 30 ms, 0 with
reduced motion), not on render callbacks; no Material; no head pose anywhere; spares carry no collider.
